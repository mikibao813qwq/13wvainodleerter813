  夢角 · PWA 完整版 — 部署說明（Android / 電腦通用）
============================================================

【這個版本新增了什麼】
  ✅ 自動保存（任何操作即時落盤 + 每日快照）
  ✅ 版本遷移（將來更新結構時，舊資料自動升級，升級前先備份）
  ✅ 數據校驗（資料損壞時不會整個網站崩掉）
  ✅ 多重備份：①自動 ②全量JSON ③僅聊天JSON，導入可選「覆蓋 / 合併」
  ✅ Service Worker（離線緩存，沒網也能開）
  ✅ 鎖屏通知（夢角發消息時手機彈窗 — 需授權通知權限）
  ✅ 可安裝到手機桌面（像原生 App 全屏）

============================================================
一、電腦本機測試（最快，雙擊就能看，但「鎖屏通知」要 https）
============================================================

  方式 A：直接打開（功能齊全，除通知外都能用）
    雙擊 index.html → 用 Chrome 打開即可
    ⚠️ 此時網址是 file:// ，Service Worker 不會生效、通知也無法彈
       （這是瀏覽器安全限制，不是壞掉）

  方式 B：本機伺服器（推薦測試，能完整啟用 SW + 通知）
    1. 在這個資料夾打開終端機 / 命令提示字元
    2. 擁有 Python 的話執行：  python3 -m http.server 8080
       沒 Python 的話：         npx serve .
    3. 瀏覽器打開  http://localhost:8080
    4. 用手機的話：電腦手機同網路，手機打  http://<電腦IP>:8080

============================================================
二、放到網路上（Android 手機能「安裝 + 鎖屏通知」的唯一方式）
============================================================
   關鍵：瀏覽器規定「安裝到桌面 / 鎖屏推送」一定要 https 網址。
   所以要把這整個資料夾上傳到「有 https 的網頁主機」。

   ★ 最推薦：GitHub Pages（完全免費，自動 https）

   步驟：
   1. 去 https://github.com 註冊並登入
   2. 右上角 New repository → 名字隨意（如 mengjiao）→ 選 Public → Create
   3. 進到倉庫 → Add file → Upload files
      → 把這個資料夾裡【全部 4 個檔案 + icons 資料夾】拖上去
      （index.html / manifest.json / sw.js / icons/ 整個資料夾）
      → Commit changes
   4. Settings → Pages → Branch 選 main → Save
   5. 等 1~2 分鐘，會得到網址：
        https://<你的帳號>.github.io/<倉庫名>/
   6. 用手機 Chrome 打開這個網址：
      ✅ 會看到「安裝應用程式」提示 → 加到主畫面（像原生 App）
      ✅ 夢角發消息時會彈窗 + 鎖屏通知（第一次會問你要不要允許）

   其他選擇（也都免費或很便宜）：Netlify Drop、Cloudflare Pages、
   Vercel、Firebase Hosting —— 都是把資料夾拖上去就自動 https。

============================================================
三、通知權限（很重要，請照做）
============================================================
  - 第一次夢角要發通知時，Chrome 會彈出「是否允許通知？」
    → 一定要按【允許】
  - 如果不小心按了「封鎖」：
    網址列左邊點一下 → 網站設定 → 通知 → 改成「允許」
  - iPhone Safari：支援有限，只能用「加到主畫面」的 basic 通知；
    Android Chrome / Edge：完整支援鎖屏推送（你用的平台沒問題）

============================================================
四、資料備份建議（一次就夠，但建議養成習慣）
============================================================
  - 設定 → 數據管理 → 「全量備份」→ 下載一份 .json 存好
  - 換手機時：新機打開網站 → 數據管理 → 「導入備份檔案」→ 選那份 json
    → 聊天、字卡、表情、設定、頭像全部回來

疑難排解
============================================================
  Q: 開起來沒反應 / 空白？
  A: 確認是用 http://localhost 或 https:// 打開，不是 file:// 直接雙擊
     （file:// 下 PWA 功能不啟用，但網站本身仍能跑）

  Q: 通知沒彈出？
  A: 檢查 ①https 網址 ②通知權限=允許 ③數據管理裡「夢角發消息手機彈窗」=開

  Q: 改了程式碼但手機沒更新？
  A: Service Worker 會緩存；改完請在網址後加 ?v=2 強制刷新，
     或開 Chrome 開發者工具 → Application → Service Workers → Update

  Q: 資料不見了？
  A: 先看瀏覽器的 localStorage（開發者工具 → Application → Storage）
     本機資料不會自動同步到別台裝置，要靠「導入/導出」搬移
